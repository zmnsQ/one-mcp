## 可重现命令

在 gateway 目录运行：

```sh
npm ci --ignore-scripts --no-audit --no-fund --cache .npm-cache
npm test
```

`npm test` 依次执行 `npm run build`、`node validation/smoke.mjs`、`node validation/advanced-smoke.mjs`、`node validation/workflow-smoke.mjs`。本轮最终日志为 `validation/test-current.log`；日志和本地依赖缓存不提交到仓库。

最初默认 npm cache 指向当前环境不可写目录，第一次依赖安装失败；改用本项目下 `.npm-cache` 后从 package-lock 成功安装全部 98 个依赖。最终测试是在此次真实安装和构建后执行，不沿用包内历史测试日志。

## 本轮修复

1. 生命周期隔离：初始化结束前不暴露 HTTP 路由；关闭期间不能复活实例；只删除当前实例对应的映射；在途停止操作纳入关闭等待；重复启动不会把仍正常运行的实例误报为 error。
2. 工具目录：并发发现去重；分页发现整体最多 15 秒；拒绝重复工具名与循环分页；tools/list_changed 立即移除旧路由并刷新 App；失败清空缓存，不继续路由旧工具；一个异常上游不会令所有健康上游的聚合工具不可见。
3. 请求边界：绝对/非法请求目标安全返回错误；严格校验 JSON content-type；即使空 Origin 也拒绝；超大请求返回 413；不支持的方法提供 Allow: POST；异常不会变成未处理的异步 HTTP rejection。
4. 配置与隐私：拒绝空/星号白名单项目、NUL 字符和无效路径类型；重叠环境变量值按长度降序脱敏；stderr 始终隐藏且限频；上游环境不继承父进程无关凭据。
5. 取消与恢复：工具调用组合 HTTP 和服务器生命周期取消信号；每上游并发上限 4；实际验证客户端断开、60 秒超时、进程崩溃和初始化过程中 SIGTERM 后均可正确清理。
6. npm test 现在是统一构建和验证入口。

4. 聚合只读工具调用

7. 浏览器 Origin 拒绝

### 原有扩展场景重新执行：8 项

1. 网关默认不启动上游、不暴露工具
2. 空白名单同时拒绝列举和调用
3. 同名工具别名独立、长度有界且调用正确
4. App IPC 提供 inputSchema 与公开别名
5. 非绝对可执行路径产生可恢复错误状态
6. 非 loopback Host 拒绝
7. 停止后独立路由立即移除
8. 关闭清理多个上游进程

### 新增真实工作流检查：18 项

1. 初始化和发现结束前隐藏启动中的服务器
2. 仅继承基础环境及明确传入的值，不继承父进程无关凭据
3. 重复启动失败保留运行状态和现有路由
4. 重复工具名、循环分页失败且不遗留路由
5. 多页工具目录完整发现
6. 十个并发发现仅产生一次上游目录请求
7. tools/list_changed 更新 App 目录并删除过时工具路由
8. 失败刷新清除旧路由且聚合出口保留其他健康工具
9. 失败目录通过同 id 停止和重启恢复
10. 异常请求目标、空 Origin、错误 content-type、JSON 与批处理安全拒绝
11. 超大流式请求返回 413 且网关仍可访问
12. notifications/initialized 返回 202
13. 第五个并发调用被拒绝，四个客户端断开均传播取消且释放容量
14. 上游异常退出移除路由并允许同 id 重启
15. 发现错误中的重叠环境变量秘密完整脱敏后再经 IPC 输出
16. 实际 60 秒工具超时发送上游取消，后续调用仍成功
17. 多上游和在途操作测试后网关正常关闭
18. 初始化时收到 SIGTERM 不会再产生 running 状态

## IPC 兼容性

未新增或改名管理方法、响应字段或事件类型，状态仍为 running/stopped/error。tools 事件现在也在 HTTP 发现和上游 list_changed 时发送。stopServer 要求合法 serverId；重复启动返回 ok:false，但不会为仍在运行的原实例发送 error 状态。超过 1 MiB 的 HTTP 请求现在明确返回 413。

## 未通过本轮证明的内容

- macOS/Xcode 编译、签名、公证、原生进程管理和 Keychain。
- 实际第三方 MCP 工具、用户权限、MCP 服务器自身的副作用撤销能力。
- 官方 tunnel-client、OpenAI 认证、ChatGPT 远程调用与实际 Host/Origin 转发行为。
- resources、prompts、sampling、elicitation、异步 task 工具和远端 HTTP 上游。
- 无会话 HTTP 无法安全关联另一个 POST 中的 notifications/cancelled；当前取消路径是断开原 HTTP 请求或停止实例/网关。

本轮验证只说明网关在上述 Linux、SDK 版本和测试输入下通过，不代表产品已完成真实 Mac 或外部端到端验收。
