# 全部启动实现与验证

## 边界

- 默认兼容旧配置。可选 startWithAll=false 只表示不参与全部启动，不是全局禁用；Swift/CLI 均保留该字段。
- 按网关 → 参与 MCP → 当前模式的隧道顺序，等待真实回执和运行状态。现有实例保持原样，待重启提示不消失。
- 一次确认涵盖程序执行与已配置 OpenAI 隧道的数据传输。聚合隧道可能包含当前实例其他已运行服务的白名单工具，确认文案明确提示。
- 确认框绑定当时的配置/工作空间/磁盘版本；确认期间变化需重新确认。每次提交检查固定磁盘版本并持有短配置租约，避免外部配置尚未被界面刷新时启动旧目标。网关启动在此流程中也不重新序列化配置。
- 不自动保存用户未保存的修改；不自动 init profile、创建/读取新凭据、扩展白名单。缺失条件逐项报错。
- 单批次执行、防双击；隧道命令按 key 跟踪 pending，避免进程状态事件到达前重复提交。
- 取消、停止、工作空间/配置变化后不继续提交；已经提交的操作不回滚。超时保留 pending 标记，不凭超时重放。
- 部分失败不影响其他独立目标；缺少成功 MCP 时不启动对应隧道。再点全部启动跳过已运行项，可重试失败项。
- 隧道启动回执仅表示提交/进程启动，随后退出和 ready 状态更新结果；不声称 ChatGPT 端到端成功。

## 测试

- npm run build：TypeScript 编译。
- validation/start-all-smoke.mjs：真实配置读写验证旧配置兼容、布尔类型、CLI持久化不丢排除标记；原生源码契约检查依赖顺序、单批次、取消、pending 防重与不创建 profile/凭据。
- Tests/MCPHarborTests/StartAllTests.swift：参与开关编解码、已运行/排除项跳过、双击、未保存修改不写盘、配置变化中止、隧道退出刷新结果。需要 macOS 执行；Linux 没有执行原生 Swift/UI，源码契约不是原生运行测试。
- 沿用 gateway 全套隔离模拟测试。当前云端不支持 Unix socket，显式 ONEMCP_SKIP_SOCKET_TEST=1 时须将相关 IPC 集成标为未验证。
