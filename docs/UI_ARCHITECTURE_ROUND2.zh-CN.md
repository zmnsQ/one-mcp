# 第二轮：整体导航、三页信息架构与原生弹窗

基线：`6a110f15f68a5e63820de88896de7767452bfff5`。这轮不是只调整卡片圆角，而是改变默认信息顺序、导航和主要弹窗构成。仅云端改代码；不改变协议、凭据、授权策略或生产服务。不伪造原生截图。

## 可直接观察的变化

| 区域 | 新组织方式 |
| --- | --- |
| 左侧品牌/空间 | 品牌标记与标题层级、当前工作空间材质容器、单独创建入口 |
| 左侧菜单 | 工作空间/管理分区，54pt图标导航行，选中状态光带、图标位移、阴影与淡色底；hover和焦点独立 |
| 底部运行 | 材质状态dock，真实网关图标和运行计数，主启动/次停止；独立有界滚动，活动展开不会把导航挤出窗口 |
| MCP服务 | 查找列表＋任务导向详情；默认“使用与授权”，说明用途、实际可用状态和下一步；“程序配置”才展示路径参数、CLI、环境值与移除 |
| 服务筛选 | 无匹配可清除；当前打开服务被过滤时明确提示，避免以为正在编辑搜索匹配项 |
| 隧道 | 首先展示连接用途、真实运行/异常/未知统计、绑定工具和主动作；安装/共享认证/请求观测按需进入维护 |
| 设置 | “连接与运行”与“安全与数据”两列，窄宽单列；使用单份AnyLayout保留子视图身份，不以重复ViewThatFits树切换 |

## 弹窗覆盖清单

- 新建工作空间：图形标题、安全提示、明确名称输入与创建/取消。
- 添加 MCP：图形标题，导入/手动两条路径及其说明。
- 应用操作确认：原生sheet图形警示、完整原始影响说明、分隔操作栏；无默认Enter执行，取消/关闭清空pending。`approve`工作空间/网关/bridge快照校验不变。
- 导入预览：安全说明、候选层级、选中计数、禁用原因与底部动作。
- 服务日志：图形标题、筛选工具层、独立阅读表面，跟随/脱敏逻辑不变。
- AI管理：图形标题、安全提示、可复制提示词层级与实际复制反馈。
- 隧道详情/编辑：图形标题，账号/绑定/传输/Profile/高级维护分层，固定操作区与保存错误提示。
- 运行状态详情：图形标题、真实状态分组和启动结果。

系统文件选择/Keychain权限提示、隧道授权确认保留系统原生呈现与动作语义。全局错误alert保留，保证编辑sheet打开时错误仍可呈现，不用第二张自定义sheet遮蔽错误。

## 安全与交互

没有自动启停、自动授权、假成功或定时模拟进度。未改变保存/权限逻辑。降低动态效果时禁用导航位移/过渡；选中态有文本值与图形标识，不只用颜色。界面采用系统语义色/材质，沿用第一轮主按钮、卡片和数值反馈。

## 检查及局限

云端全Swift语法解析、7项新架构契约、8项第一轮UI契约、12项既有可用性契约、状态模型、隧道卡片、日志跟随/脱敏、活动、工具选择、创建与凭据策略检查通过。独立源码review指出的搜索误认、侧栏溢出、重复设置子树身份丢失均已修复。

这轮未做macOS类型检查/实际渲染。此前v2的原生构建和鼠标观察不代表本轮通过；历史ToolSelectionTests权限保存断言在基线也失败，未为测试放宽权限。系统Full Keyboard Access关闭时Tab遍历受限，不判为产品缺陷，也没有修改系统设置。用户已要求推Git后自行拉取编译体验，不用额外Mac验收阻塞交付。

## 托盘菜单（同轮补充）

保留 `MenuBarExtra.window` 原生可交互面板：顶部品牌、当前工作空间、真实网关图形状态与运行计数；中段主窗口/明确确认后的全部启动，以及有界滚动的服务/隧道状态；底部停止连接、设置和退出。静态状态行仍用高对比正文，不伪装成禁用菜单项。全部启动复用配置/工作空间/revision快照校验和原生确认，不自动执行。

“设置”使用纯展示路由 mailbox：先记录目的地，再打开窗口；首次窗口尚未创建也不会丢失目的地，不写配置或启动后台任务。退出仍交既有AppDelegate处理未保存修改和连接生命周期。
