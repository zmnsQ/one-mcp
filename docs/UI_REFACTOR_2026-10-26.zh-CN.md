# One MCP UI 重构 · 2026-10-26

基线：GitHub main `8d8de70`，全新助手云端 checkout；没有覆盖历史工作区或连接用户 Mac。仅界面/展示状态与测试变更，不改 MCP 协议、凭据、网关配置、日志脱敏或授权策略。

## 前后变化

| 原界面 | 本轮实现 |
| --- | --- |
| 总览/隧道/设置分别写卡片背景和边框 | `harborSurface` 统一 18pt 圆角、18pt 内边距、语义颜色；轻微渐变光照和有层次阴影，hover 180ms 过渡，不移动卡片 |
| 标题只有文本 | 原生符号色块＋清晰标题/说明层级，浅渐变页头；页面切换 200ms 淡入/8pt 位移 |
| 主次按钮不突出，中文复制按钮挤占卡片 | 单一主动作填充渐变/阴影，按压缩至 0.97 后短弹簧恢复；复制放更多菜单并显示真实剪贴板成功反馈 |
| 指标静态跳变 | 圆角数字/等宽数字与 240ms 数值过渡，仅真实值改变触发 |
| 长名/错误混在操作中 | 两行长名、操作等待状态、就地禁用原因/诊断提示，不把提交当成功 |
| 全服务堆叠 | 总览本地名称/ID筛选、无匹配可清除；⌘1…4 导航，无启动快捷键 |
| 设置展开跳变 | 保留整行44pt命中区及键盘展开，180ms展开与箭头旋转 |
| 日志无显式跟随控制 | 手动滚动暂停，查看最新恢复；可见/总数、增量计数与过滤空态 |

无无限循环装饰动画；Reduce Motion 禁用位移、缩放、数值动画、符号替换，等待用静态沙漏替代旋转；高对比加强描边。日志不加滚动动画。仍需原生验证实际键盘焦点、系统动画组合及对比度。

## 参考来源与取舍

- https://github.com/Caho1/open-claude-ui ：仅参考交互原则，不复制其品牌、素材或实现代码。
- `code-examples/cds-theme.css`：语义 Surface 层次、状态/焦点一致性；改用 macOS 系统颜色。
- `code-examples/CdsButton.tsx`：loading 防重入；本项目只显示实际网关 pending/状态。
- `code-examples/useClaudeScrollPinning.ts`：用户上滚不抢位；本项目用 SwiftUI scroll phase 与显式跟随状态实现。
- `McpToolDecisionCard.tsx` 的定时模拟成功不采用；`ConfirmationDialog.tsx` 未完整实现焦点约束，不移植，仍使用原生 sheet/alert。
- 输入筛选不绑定 Enter 执行，不添加 IME 风险；没有新增假进度或自动重试。

## 原生首轮编译反馈与修正（07:14 UTC）

macOS 27.0.1 / SDK 27 / Swift 6.4 arm64 原生编译发现 Preview 对只读 `accessibilityReduceMotion`、`colorSchemeContrast` 使用 `.environment` 导致 KeyPath/WritableKeyPath 编译错误。已移除这两项非法 Preview 注入，生产组件对真实系统环境的读取与响应保持不变。原生首轮未运行测试用例或 UI；本修正云端 parse/契约检查通过仍不等于原生复验通过。高对比/减少动画现待用户自测或另行授权变更系统设置后进行真实验收，当前 Mac 测试线程不得擅自切换；不宣称 Preview 已覆盖。
