# 已保存配置与运行配置同步验证

2026-10-17，助手云端 Linux；未连接用户 Mac、真实 MCP 服务或真实隧道。

## 行为

- 无本地未保存修改时，现有一秒轮询会直接载入有效外部配置，包括网关运行期间。
- 未保存修改保留，必须明确选择载入磁盘版本；写入仍受配置版本和短时锁保护。
- 无效、不可读取或过大的外部文件不会替换最后有效界面内容；首次启动尚未保存文件不会误报。
- 运行快照只更新运行状态，不回写已保存配置。逐字段版本化指纹比较网关、MCP 和隧道实际使用的配置。
- 新增项目不自动启动；删除但仍运行的服务、隧道保留停止入口；仅受影响的运行项目显示待重启原因。
- 路由模式是界面选择，不会凭空标记 MCP 需要重启；工具目录热更新也不会改变启动配置指纹。
- 环境变量值和隧道密钥不进入指纹或新增诊断。旧版本缺少对比元数据时显示无法核对，不冒充已生效。

## 已执行

- TypeScript 构建、包入口检查和 `git diff --check`。
- 新增真实子进程回归：实际 CLI 保存白名单、端口、profile 和模式后，原网关 PID、运行权限、隧道及配置指纹保持不变；明确重启服务和隧道后，各自指纹采用新值，网关端口仍不变。
- 指纹逐字段隔离、集合排序、Unicode、空值、路径符号链接和跨语言固定测试向量。
- 原有 HTTP / stdio 网关模拟回归，包括真实 60 秒调用超时、启动、关闭、工具发现和并发限制。
- 原生修改经过独立静态代码检查。

## 限制

- 完整 `npm test` 在 CLI 私有 Unix socket 集成处被云端沙箱的 `listen EPERM` 阻断；不能声称完整集成全部通过。CLI 非 socket 部分使用测试已有的 `ONEMCP_SKIP_SOCKET_TEST=1` 单独执行。
- Unix socket 专属测试尚未完成；纯逻辑和 stdin 子进程测试不等同于该集成。
- 当前 Linux 没有 Swift/macOS SDK，新增 `ConfigurationApplicationTests` 与 SwiftUI 编译/运行未执行。原生测试覆盖运行时载入、编辑冲突、无效文件、增删、断线重连、旧协议、逐项原因和跨语言向量，但仍需 macOS 测试环境执行。
- 未自动触发 GitHub Actions，未在用户设备启动程序，也未生成已验证的 macOS 应用包。
