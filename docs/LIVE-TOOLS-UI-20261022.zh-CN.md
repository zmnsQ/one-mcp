# 工具热更新与状态界面

基线：main `95ca10b981bdd4bc478db3c610d186400dd9c6f9`。保留隧道 Profile 创建和凭据复用实现。

## 之前为何必须停止

原界面的工具 Toggle 被 `running` 禁用，网关只在 `startServer` 时接收 `allowedTools`，没有单独更新白名单的管理命令。这是实现限制，不是 MCP 协议要求。

MCP 2025-11-25 工具规范定义 `tools/list` 和可选的 `listChanged` 能力；声明该能力的服务应发送目录变化通知。One MCP 当前出口是无会话 Streamable HTTP，GET/SSE 不可用，因此仍不声明 `listChanged`，也不承诺客户端自动刷新。

官方来源：https://modelcontextprotocol.io/specification/2025-11-25/server/tools#list-changed-notification

## 新行为

- 工具按当前服务直接显示为卡片：名称、用途、开关、授权状态；可搜索，显示目录/选择/运行授权计数。技术 schema 按需展开。
- 开关只修改草稿。“保存并应用工具选择”才更新运行权限；确认期间配置、工作空间或权限发生变化则拒绝旧确认。
- 只保存该服务的工具选择，不连带保存其他进程/连接草稿。
- 新 `updateAllowedTools` 管理命令对当前白名单做比较交换，严格校验参数，原子替换授权。服务进程、连接、其他服务和隧道绑定保持不变，在途调用继续完成。
- 下一次工具列表/调用使用新白名单；停用后的新调用立即拒绝。客户端缓存需要刷新工具或重连。工具变化不会自动增加 OAuth 权限、修改凭据或增加隧道绑定。
- 旧运行组件不支持热更新时给出一次组件升级提示，不伪装已生效。更新组件后需重启网关一次；以后改工具无需停服。
- 进程配置改成常用字段直接展示、高级设置折叠；运行中仍锁定进程/CLI 定义，避免把启动参数改动误当热更新。
- 侧栏记录具体配置动作、对象和结果，区分草稿保存/待应用/已生效/失败。当前配置文件没有可靠的 AI 作者身份字段，因此外部写入标为“外部更新（来源未确认）”，不谎称来自 AI；运行事件标系统。摘要不显示命令、参数值、凭据或原始错误。
- 托盘为隧道和 MCP 保留非零滚动区域，隧道优先展示；状态来自配置与实际运行事件合并，断开时显示未知。移除常驻“就绪不代表……”说明。

## 后续：每服务日志

- 总览每张 MCP 卡和服务详情都有“日志”入口，实时更新，支持仅错误过滤和只清空当前服务。
- 按稳定服务 ID 严格隔离，每服务最近 300 条、最多 32 个服务缓冲；切换工作空间清除，不落盘。
- 记录网关观察到的启动、运行、停止、异常断连，以及调用开始、完成、工具失败、超时和取消。服务 A 的繁忙日志不会挤掉服务 B 的缓冲。
- 不把 stdio stdout JSON-RPC 协议当普通日志。上游 stderr 仅显示“收到标准错误”诊断标记，不放出原文；原始异常、Authorization、URL token、请求参数和返回内容不进入独立日志。采用固定字段/固定消息映射，不依赖正则猜测秘密。
- 这些是本机网关观测日志，不是远端 MCP 内部日志；共享网关仅能补入当前近期事件，非完整历史。限制说明收在“记录范围”中。
